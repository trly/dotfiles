# Product

## Register

product

## Users

trly, a single user on a Linux desktop. Developer workflow — terminal-heavy, keyboard-driven. The bar provides glanceable system information during focused work sessions.

## Product Purpose

A Wayland status bar (Waybar) that surfaces essential system state at a glance: workspaces, system resources (CPU, memory, temperature), audio, network, battery, clock, MPD playback, and quick power actions. Success looks like informing without interrupting — the bar is readable when looked at and invisible when not.

## Brand Personality

Sharp, technical, muted. Confident and understated. Not flashy, not sterile. Adjacent to terminal/developer aesthetics but with deliberate polish.

## Anti-references

- Garish/gaming aesthetic: neon gradients, RGB extremes, aggressive contrast
- Default Waybar: uncoordinated colors, no cohesive palette
- MacOS menu bar clone: frosted glass, pill modules, borrowed visual language
- Stock desktop taskbars (GNOME, Windows): generic, utilitarian, no point of view

## Design Principles

1. **Understated clarity** — Information is glanceable without demanding attention. The bar recedes until needed.
2. **Cohesive restraint** — A unified palette with intentional accents. Every color serves a purpose.
3. **Technical precision** — Clean spacing, aligned elements, sharp hierarchy. Feels engineered, not painted.
4. **Context over decoration** — Color communicates state (critical battery, muted audio, urgency), not ornament.
5. **Low fatigue** — Muted tones, no gratuitous motion. Calm persistence.

## Accessibility & Inclusion

Standard readability. No special requirements beyond clear text contrast against the bar background.
